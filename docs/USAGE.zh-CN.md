# RSS Telegram Bot 完整使用手册

这份手册按实际使用顺序说明每条命令。机器人每 10 秒检查一次 RSS；首次读取某个源时只建立去重基线，**不会补发历史文章**，之后发现的新文章才会进入推送判断。

## 先看懂命令写法

- `<内容>` 是**必填**参数，必须替换为你的实际内容，不能连尖括号一起发送。
- `[内容]` 是**可选**参数，可以不填。
- 多个关键词、屏蔽词或版块 ID 用英文逗号 `,` 分隔；不要用中文逗号 `，`。
- `源 ID`、`关键词 ID`、`屏蔽词 ID`、`目标 ID` 是不同的编号。每次先用对应的查看命令确认编号，不能互相替代。

例如：`/subscribe 1` 里的 `1` 是 RSS 源 ID；`/delkw 3` 里的 `3` 是关键词 ID。

## 3 分钟开始使用

请在与机器人的**私聊**中依次发送：

```text
/start
/feeds
/subscribe 1
/all 1 on
/status
```

含义如下：

1. `/start`：启用机器人，并将当前私聊自动加入推送目标。
2. `/feeds`：查看管理员添加的 RSS 源及其源 ID。
3. `/subscribe 1`：订阅列表中 ID 为 `1` 的 RSS 源。
4. `/all 1 on`：让源 `1` 的后续新帖子全部推送。
5. `/status`：检查订阅和推送目标是否已生效。

如果你只想收到特定内容，把第 4 步换成：

```text
/keywords OpenAI,AI
```

这会添加两个普通关键词；标题或摘要包含其中任意一个时才会推送。使用关键词模式时，不要开启该源的全量推送，或执行 `/all 1 off` 关闭它。

## 推送方式：全量或关键词

每个已订阅 RSS 源可以独立设置，两种方式二选一：

| 目标 | 命令 | 会发生什么 |
| --- | --- | --- |
| 查看所有已订阅源的模式 | `/all` | 显示每个源是“全量推送”还是“关键词推送” |
| 开启全量推送 | `/all 1 on` | 源 `1` 之后的每篇新帖都会推送 |
| 改回关键词推送 | `/all 1 off` | 源 `1` 只有命中关键词或组合关键词时才推送 |

全量推送仍会受以下规则限制：已选版块、屏蔽词、暂停状态；因此“全量”不是无条件推送。关键词、屏蔽词与版块是按用户保存的，不会影响其他用户。

## RSS 源与订阅

| 命令 | 怎么用 | 结果 |
| --- | --- | --- |
| `/feeds` | 直接发送 | 列出所有共享 RSS 源，例如 `1. NodeSeek` |
| `/subscribe <源ID>` | `/subscribe 1` | 订阅指定源；只能收到该操作之后的新文章 |
| `/unsubscribe <源ID>` | `/unsubscribe 1` | 取消订阅，并关闭该源的全量推送开关 |
| `/mysources` | 直接发送 | 查看你已经订阅的源及其源 ID |

管理员另外可用：

| 命令 | 怎么用 | 结果 |
| --- | --- | --- |
| `/addfeed <RSS地址>` | `/addfeed https://example.com/feed.xml` | 添加一个所有用户都可订阅的 RSS 源 |
| `/delfeed <源ID>` | `/delfeed 3` | 删除共享源 `3` 及所有人的订阅关系；推送历史保留 |
| `/feedstatus` | 直接发送 | 查看各源上次检查时间和最近错误，排查 RSS 是否能读取 |

## 关键词：普通词、组合词与开关

关键词会检查文章的**标题和摘要**；英文不区分大小写。

| 命令 | 怎么用 | 结果 |
| --- | --- | --- |
| `/keywords` | 直接发送 | 查看所有关键词、类型、关键词 ID、是否启用 |
| `/keywords <词1,词2>` | `/keywords OpenAI,Claude` | 添加普通关键词；任意一个命中即可推送 |
| `/combo <词1,词2>` | `/combo dmit,corona` | 添加组合关键词；同一篇文章必须同时命中所有词 |
| `/on <关键词ID>` | `/on 3` | 重新启用 ID 为 `3` 的关键词 |
| `/off <关键词ID>` | `/off 3` | 暂停 ID 为 `3` 的关键词，但不删除它 |
| `/delkw <关键词ID>` | `/delkw 3` | 永久删除 ID 为 `3` 的关键词 |

例子：先发送 `/keywords`，机器人回复 `3. 普通：OpenAI ✅`；其中 `3` 才是后续 `/off 3` 或 `/delkw 3` 使用的关键词 ID。

## 屏蔽词：优先级高于推送模式

| 命令 | 怎么用 | 结果 |
| --- | --- | --- |
| `/block <词1,词2>` | `/block 求购,已出` | 添加屏蔽词；命中任一屏蔽词的文章不会推送 |
| `/blocks` | 直接发送 | 查看屏蔽词及其屏蔽词 ID |
| `/delblock <屏蔽词ID>` | `/delblock 2` | 删除 ID 为 `2` 的屏蔽词 |

屏蔽词即使在全量推送模式下也会生效。若发现某类内容始终不推送，请先执行 `/blocks` 检查是否误加了屏蔽词。

## 版块筛选：先查 ID，再选择

版块由 RSS 自己提供；不同源的 ID 不同，不能猜测或照搬别的源的数字。没有选择任何版块时，表示该源的**全部版块**都可以推送。

第一步，查看源 `1` 实际发现的版块：

```text
/sections 1
```

机器人会按数字由小到大返回类似内容：

```text
版块（未选择任何版块表示全部）：
1. 日常（daily）
3. 交易（trade）
5. 拼车（carpool）
8. 评测（review）
10. 情报（info）
142. 技术（tech）
```

第二步，选中想要的版块。例如只收日常和技术：

```text
/sections 1 1,142
```

第三步，如要恢复源 `1` 的所有版块：

```text
/clearsections 1
```

常见 RSS 标签会显示为“中文（英文）”。例如 NodeSeek 的 `daily / tech / info / review / trade / carpool / promotion` 分别会显示为日常、技术、情报、评测、交易、拼车、推广。`DeepFlood` 和“邮箱”是外部链接，不是可筛选的 NodeSeek 版块。

## 推送目标：私聊、群组、频道

每位用户默认最多配置 10 个目标；一个用户的规则可同时推送到其所有目标。

| 使用场景 | 命令/操作 | 必要条件 |
| --- | --- | --- |
| 私聊 | `/start` | 当前私聊会自动添加，无需 `/addtarget` |
| 群组 | 将 Bot 加入群后，在群里发送 `/addtarget` | 操作者是群管理员；Bot 有发消息权限 |
| 频道 | 将 Bot 加入频道并设为管理员；私聊 Bot 发送 `/addtarget <chat_id>` | 操作者也是频道管理员；`chat_id` 一般以 `-100` 开头 |
| 查看已绑定目标 | `/targets` | 返回每条目标的“目标 ID” |
| 删除一个目标 | `/deltarget <目标ID>`，如 `/deltarget 2` | 只删除 ID 为 `2` 的目标 |

绑定频道时，机器人必须先在该频道内，才能验证你拥有管理员权限并发送消息。

## 查询、历史与暂停

| 命令 | 怎么用 | 结果 |
| --- | --- | --- |
| `/status` | 直接发送 | 查看订阅数、全量源数、关键词、屏蔽词、目标数与轮询间隔 |
| `/history [数量]` | `/history` 或 `/history 30` | 查看最近命中的帖子；默认 10 条，最多 50 条 |
| `/pause` | 直接发送 | 暂停你自己的所有提醒，保留配置 |
| `/resume` | 直接发送 | 恢复你的提醒 |
| `/whoami` | 直接发送 | 显示你的 Telegram 数字 ID，供管理员配置权限使用 |
| `/help` | 直接发送 | 在 Telegram 中显示按使用顺序整理的命令速查和示例 |

## 通知消息的样式

每条通知的顶部标题和下方原生网页预览卡片都可点击，并会直达原帖。预览卡片的颜色、图片、摘要由 Telegram 和原网页的元数据决定，机器人无法单独改变卡片背景。新样式仅对之后推送的新消息生效，旧消息不会重新渲染。

## 收不到推送时，按此顺序检查

1. 私聊先发送 `/start`，再用 `/targets` 确认至少有一个目标。
2. 用 `/mysources` 确认订阅了正确的源；若没有，先 `/feeds`、再 `/subscribe <源ID>`。
3. 用 `/all` 确认该源是全量推送；若不是，确认 `/keywords` 至少有一个带 `✅` 的规则。
4. 如果设置过版块，执行 `/sections <源ID>`，确认帖子所属版块在已选数字中；不确定时用 `/clearsections <源ID>` 恢复全部。
5. 用 `/blocks` 排除屏蔽词；全量推送也会被屏蔽词拦截。
6. 首次添加源或首次订阅后，等待 RSS 发布**新的**文章；机器人不会补发旧文章。
7. 执行 `/status` 确认没有暂停；管理员可执行 `/feedstatus` 检查源是否报错。

## 多人共用与权限

RSS 源由管理员共享；每位用户的订阅、全量推送模式、关键词、屏蔽词、版块、推送目标和暂停状态互相独立。若服务器设置了 `ALLOWED_USER_IDS` 白名单，只有列出的 Telegram 用户 ID 能使用机器人；管理员还必须在 `ADMIN_USER_IDS` 中配置。
