# RSS Telegram Bot 使用手册

本机器人从已添加的 RSS 源抓取新帖子，按每位用户自己的订阅、推送模式、版块、关键词和屏蔽词决定是否发送。默认每 10 秒检查一次。

## 最快开始

在与机器人的私聊中依次发送：

```text
/start
/feeds
/subscribe 1
/keywords OpenAI,AI
```

`/start` 会将当前私聊设为推送目标；`/feeds` 显示可用源和编号；`/subscribe 1` 订阅源 1；最后一条添加普通关键词。首次抓取只建立基线，历史文章不会补发，之后出现的新文章才可能推送。

## 推送方式：关键词或全量

每个 RSS 源都可独立选择模式。

| 目标 | 命令 | 结果 |
| --- | --- | --- |
| 查看每个订阅源的模式 | `/all` | 显示“关键词推送”或“全量推送” |
| 对源 1 开启全量推送 | `/all 1 on` | 源 1 后续全部新帖推送 |
| 对源 1 关闭全量推送 | `/all 1 off` | 源 1 恢复为仅关键词命中推送 |

全量推送仍会遵守已选版块、屏蔽词、暂停状态和目标数量限制。关键词推送模式下，至少要有一个启用的关键词或组合关键词才能收到消息。

## 推送消息样式

每条通知只显示可点击的置顶标题；下方保留 Telegram 根据原帖链接自动生成的原生网页预览卡片。点击顶部标题或下方预览卡片都能直达原帖，不再额外显示“命中”或“打开原帖”文字。预览的背景、图片和摘要均由 Telegram 与原帖网页决定，机器人无法自定义。旧消息不会被 Telegram 重新渲染；升级样式后只影响新消息。

## RSS 源与订阅

| 命令 | 谁能使用 | 说明 |
| --- | --- | --- |
| `/feeds` | 所有获准用户 | 查看所有共享 RSS 源和源 ID |
| `/subscribe <源ID>` | 所有获准用户 | 订阅一个源，例如 `/subscribe 1` |
| `/unsubscribe <源ID>` | 所有获准用户 | 取消订阅；同时关闭该源的全量推送设置 |
| `/mysources` | 所有获准用户 | 查看自己订阅的源 |
| `/addfeed <RSS地址>` | 管理员 | 添加共享 RSS，例如 `/addfeed https://example.com/feed.xml` |
| `/delfeed <源ID>` | 管理员 | 删除共享源和所有人的订阅关系；历史记录仍保留 |
| `/feedstatus` | 管理员 | 查看每个源最近检查时间与抓取错误 |

添加源后先用 `/feeds` 得到编号，再由每位用户自行 `/subscribe`。

## 关键词与屏蔽词

| 命令 | 说明 |
| --- | --- |
| `/keywords` | 查看自己的关键词、组合关键词、ID 和开关状态 |
| `/keywords 词1,词2` | 添加普通关键词；任意一个命中即可推送 |
| `/combo 词1,词2` | 添加组合关键词；同一篇帖子必须同时包含全部词才推送 |
| `/on <关键词ID>` | 开启一条关键词，例如 `/on 3` |
| `/off <关键词ID>` | 暂停一条关键词，不删除规则 |
| `/delkw <关键词ID>` | 永久删除一条关键词，例如 `/delkw 3` |
| `/block 词1,词2` | 添加屏蔽词；命中时不推送，即使开启全量推送 |
| `/blocks` | 查看屏蔽词和 ID |
| `/delblock <屏蔽词ID>` | 删除屏蔽词 |

逗号必须使用英文逗号 `,`。匹配会检查标题与摘要，且不区分英文大小写。

## 版块筛选

部分 RSS 提供分类/版块标签。先查看源的版块：

```text
/sections 1
```

机器人会列出源 1 的版块 ID。再选择多个版块：

```text
/sections 1 2,5,9
```

只会推送上述版块的新帖。恢复订阅该源的全部版块：

```text
/clearsections 1
```

若 RSS 本身不提供分类，`/sections` 会提示尚未发现版块。

## 推送目标：私聊、群组和频道

每个用户默认最多有 10 个目标，使用 `/targets` 查看。

| 场景 | 操作 |
| --- | --- |
| 私聊 | 发送 `/start`，当前私聊自动成为目标 |
| 群组 | 将 Bot 加入群，且你和 Bot 均具备所需权限；在群内发送 `/addtarget` |
| 频道 | 将 Bot 加入频道并设为管理员；在私聊中发送 `/addtarget <频道chat_id>` |
| 查看目标 | `/targets` |
| 删除目标 | `/deltarget <目标ID>` |

群组或频道绑定时，机器人会验证操作者是管理员。频道 `chat_id` 通常为以 `-100` 开头的数字。

## 状态、历史与暂停

| 命令 | 说明 |
| --- | --- |
| `/status` | 查看订阅数量、全量推送源数、关键词、屏蔽词、目标和轮询间隔 |
| `/history` | 查看最近 10 条已命中帖子 |
| `/history 30` | 查看最近 30 条，最多 50 条 |
| `/pause` | 暂停自己的全部提醒，规则和订阅仍保留 |
| `/resume` | 恢复提醒 |
| `/whoami` | 显示自己的 Telegram 数字 ID |
| `/help` | 在 Telegram 中显示命令速查 |

## 常见问题

**为什么没有收到推送？**

依次检查：已发送 `/start`（有推送目标）；已 `/subscribe` 对应源；开启了全量推送或至少有一个启用的关键词；新帖子是在首次抓取之后出现；帖子未命中屏蔽词，且符合已选版块。使用 `/status`、`/targets`、`/keywords`、`/all` 和 `/history` 可逐项确认。

**为什么添加 RSS 后没有马上收到旧文章？**

这是去重设计：首次读取只记录已有文章，以避免大量历史消息刷屏。之后发布的新文章才会考虑推送。

**多人共用时规则会互相影响吗？**

不会。RSS 源可共享，但订阅、关键词、版块、屏蔽词、推送目标、暂停状态和全量推送模式都按用户独立保存。
