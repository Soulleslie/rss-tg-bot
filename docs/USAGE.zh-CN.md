# RSS Telegram Bot 使用手册

这份手册先讲清楚机器人**怎么判断要不要推送**，再按使用顺序介绍每条命令。在 Telegram 里发送 `/help` 也能看到精简版说明，点消息下方的按钮可以切换到各个分类的详细说明。

## 一、先弄懂这三件事

### 1. 一篇新文章怎么决定推不推

机器人定时检查 RSS（默认每 60 秒，实际间隔可用 `/status` 查看）。发现新文章后，会对每位订阅者依次判断：

1. **订阅**：你订阅了这篇文章所在的源吗？没订阅就不推。
2. **版块筛选**：你给这个源选了版块吗？没选表示全部版块都要；选了的话，文章至少要属于其中一个版块。
3. **屏蔽词**：标题或摘要里包含你的任意一个屏蔽词？包含就不推。
4. **推送模式**（每个源单独设置）：
   - **全量推送**：通过前面几步就推送，**不检查关键词**；
   - **关键词推送**（新订阅的默认模式）：还要命中你的至少一条关键词。
5. **推送目标**：把消息发到你的**全部**推送目标（私聊、群组、频道）。

如果你发送过 `/pause`，以上全部暂停。

> ⚠️ 最常见的问题：订阅后默认是“关键词推送”。如果你既没有添加关键词，也没有开启全量推送，就**收不到任何消息**。发送 `/status`，机器人会直接提示这类问题。

### 2. 哪些设置按源分开，哪些统一生效

| 设置 | 生效范围 | 相关命令 |
| --- | --- | --- |
| 推送模式（全量 / 关键词） | **每个源单独设置** | `/all` |
| 版块筛选 | **每个源单独设置** | `/sections`、`/clearsections` |
| 关键词、组合关键词 | **只对“关键词推送”的源生效**，而且对这些源统一生效；全量推送的源不看关键词 | `/keywords`、`/combo` 等 |
| 屏蔽词 | 对你订阅的所有源**统一生效**，全量推送也会被拦截 | `/block` 等 |
| 推送目标 | 所有推送都发到**全部**目标，不能按源分别指定 | `/addtarget`、`/targets` |
| 暂停 | 暂停你的**全部**推送 | `/pause`、`/resume` |

每位用户的设置互相独立，不会影响别人。RSS 源本身由管理员添加，所有用户共享。

### 3. 四种 ID 不要混用

列表里每行开头的数字就是 ID。不同类型的 ID 是各自独立的编号，**不能互相替代**：

| ID 类型 | 用哪个命令查看 | 用在哪些命令 |
| --- | --- | --- |
| 源ID | `/feeds`、`/mysources` | `/subscribe`、`/unsubscribe`、`/all`、`/sections`、`/clearsections` |
| 关键词ID | `/keywords` | `/kwon`、`/kwoff`、`/delkw` |
| 屏蔽词ID | `/blocks` | `/delblock` |
| 目标ID | `/targets` | `/deltarget` |
| 版块ID | `/sections <源ID>` | `/sections <源ID> <版块ID>` |

例如 `/all 1 off` 里的 `1` 是**源ID**，`/kwoff 1` 里的 `1` 是**关键词ID**，两者毫无关系。

### 命令写法约定

- 本手册里的 `<内容>` 表示必填参数，要换成实际内容，**不要输入尖括号**。例：`/subscribe <源ID>` 应发送 `/subscribe 1`。`[内容]` 表示可选参数，可以不写。
- 在机器人的回复里，**蓝色的命令**（如 /feeds）直接点就会发送；**等宽字体的命令**（如 `/subscribe 1`）点一下是复制，粘贴到输入框改成自己的内容再发送。这是因为 Telegram 只会把命令名本身做成可点击的，直接点 `/subscribe 1` 实际只会发出 `/subscribe`。部分客户端需要长按才能复制。
- 多个值用逗号分隔，英文逗号 `,`、中文逗号 `，`、顿号 `、` 都可以。
- 在输入框里输入 `/` 会弹出命令菜单，菜单里有每条命令的简短说明。

## 二、3 分钟上手

在与机器人的**私聊**中依次发送：

```text
/start
/feeds
/subscribe 1
/all 1 on
/status
```

1. `/start`：开始使用，并自动把当前私聊设为推送目标。
2. `/feeds`：查看所有 RSS 源，记下行首的数字（源ID）。
3. `/subscribe 1`：订阅源 1。
4. `/all 1 on`：让源 1 的新文章全部推送。
5. `/status`：检查设置。最后一行显示“✅ 设置完整”就说明配置好了。

如果只想收到特定内容，把第 4 步换成添加关键词：

```text
/keywords OpenAI,Claude
```

只推送订阅之后出现的**新文章**，不会补发旧文章。

## 三、订阅与推送模式

| 命令 | 例子 | 作用 |
| --- | --- | --- |
| `/feeds` | `/feeds` | 列出所有源；已订阅的会标 `✅ 已订阅` |
| `/subscribe <源ID>` | `/subscribe 1` | 订阅。新订阅默认是关键词推送 |
| `/mysources` | `/mysources` | 我的订阅，以及每个源的推送模式和版块筛选 |
| `/unsubscribe <源ID>` | `/unsubscribe 1` | 取消订阅，同时清除这个源的推送模式和版块选择 |
| `/all` | `/all` | 查看每个已订阅源的推送模式 |
| `/all <源ID> on` | `/all 1 on` | 全量推送：这个源的新文章都推送，**不看关键词**（仍受版块筛选和屏蔽词限制） |
| `/all <源ID> off` | `/all 1 off` | 关键词推送：只推送命中关键词的文章 |

## 四、关键词

### 关键词对哪些源生效（重要）

关键词**只对“关键词推送”的源生效**。如果某个源开了全量推送（`/all <源ID> on`），这个源的新文章都会推送，你添加的关键词对它**不起作用**。想让关键词对它生效，要改回关键词推送：`/all <源ID> off`。

在 `/keywords`、`/mysources`、`/status` 里，全量推送的源会标注“不看关键词”；添加关键词时，如果你有全量推送的源，机器人也会提醒。

### 匹配规则（重要）

- 检查范围：默认是文章的**标题 + 摘要**，可以用 `/match` 改为只看标题，见下一节。
- 英文**不区分大小写**：`openai` 和 `OpenAI` 效果相同。
- 只要**包含**就算命中，不按单词判断。
- ⚠️ 所以很短的英文词容易误命中：`AI` 会命中 `said`、`mail`、`rain`。尽量用更完整的词（如 `OpenAI`），或用组合关键词缩小范围。添加 3 个字母以内的英文关键词时，机器人会给出提醒。

### 匹配范围：只看标题，还是标题 + 摘要

摘要是帖子正文的开头部分。正文里顺带提到的词也会触发推送，比如收购帖"+200 收一个 RFC JP T1 GOLDEN"，正文里写着"有出的老板私聊"，就会命中组合关键词 `出 + golden`。

| 命令 | 作用 |
| --- | --- |
| `/match` | 查看当前的匹配范围 |
| `/match title` | 关键词**只看标题**。适合标题里会写明"出""收"的论坛 |
| `/match all` | 看**标题 + 摘要**（默认）。能匹配到更多，但也更容易误命中 |

- 这个设置每个用户单独保存，对你所有“关键词推送”的源生效。
- **只影响关键词。屏蔽词始终检查标题 + 摘要**，所以正文里出现屏蔽词的文章照样会被拦截。
- 当前的匹配范围会显示在 `/keywords` 和 `/status` 里。

### 普通关键词：包含任意一个就推送

| 命令 | 例子 | 作用 |
| --- | --- | --- |
| `/keywords` | `/keywords` | 查看所有关键词、类型、关键词ID、是否启用 |
| `/keywords <词1,词2>` | `/keywords OpenAI,Claude` | 添加普通关键词。每个词单独成为一条，各有自己的 ID；已存在的词不会重复添加 |

添加后机器人会回复每个词的 ID，例如：

```text
✅ 已添加普通关键词（包含任意一个就推送）：
#5 OpenAI
#6 Claude
```

### 组合关键词：必须同时包含所有词

| 命令 | 例子 | 作用 |
| --- | --- | --- |
| `/combo <词1,词2>` | `/combo dmit,corona` | 同一篇文章必须同时包含 dmit **和** corona 才推送。整组只算一条关键词、一个 ID |

### 暂停、启用、删除关键词

| 命令 | 例子 | 作用 |
| --- | --- | --- |
| `/kwoff <关键词ID>` | `/kwoff 5` | 暂停关键词 5，保留不删除 |
| `/kwon <关键词ID>` | `/kwon 5` | 重新启用关键词 5 |
| `/delkw <关键词ID>` | `/delkw 5` | 永久删除关键词 5 |

旧命令 `/off`、`/on` 仍然可用，效果与 `/kwoff`、`/kwon` 相同。改名是为了避免和 `/all <源ID> off` 混淆。ID 输错时机器人会提示“没有找到”，不会假装成功。

### 关键词编号为什么会跳号

- 删除关键词后，它的编号**不会被补位**，新建的关键词继续往后编号。例如删掉 6 号后，下一个新关键词是 8 号，而不是 6 号。这样同一个编号永远只对应一条关键词，凭印象发 `/delkw 6` 不会误删后来新建的关键词。
- 编号是所有用户共用的，别人添加关键词也会让你的编号跳号。
- 编号大小不影响使用。想把编号重新整理成 1、2、3……，可以让管理员执行 `/renumber`（见“管理员”一节）。屏蔽词的编号规则与此相同。

## 五、屏蔽词

屏蔽词的匹配规则与关键词相同（标题 + 摘要、不区分大小写、包含即命中），而且**优先级最高**：全量推送的源也会被拦截。

| 命令 | 例子 | 作用 |
| --- | --- | --- |
| `/block <词1,词2>` | `/block 求购,已出` | 添加屏蔽词 |
| `/blocks` | `/blocks` | 查看屏蔽词及其 ID |
| `/delblock <屏蔽词ID>` | `/delblock 2` | 删除屏蔽词 2 |

## 六、版块筛选

版块是 RSS 文章自带的分类，每个源单独设置。**没有选任何版块，就表示全部版块都推送。**

第 1 步，查看源 1 的版块：

```text
/sections 1
```

机器人会回复类似内容（`✅` 表示已选中）：

```text
#1 NodeSeek 的版块（行首数字 = 版块ID）
当前：全部版块

1. 日常（daily）
3. 交易（trade）
5. 拼车（carpool）
142. 技术（tech）
```

第 2 步，只保留日常和技术：

```text
/sections 1 1,142
```

> ⚠️ 每次设置都会**替换**之前的选择，不是追加。想在“日常、技术”之外再加“交易”，要发送 `/sections 1 1,142,3`。

如需恢复全部版块：

```text
/clearsections 1
```

补充说明：

- 必须先订阅这个源，才能设置它的版块。
- 版块列表是从**已经抓到的文章**里收集的。刚添加的源，或者近期没人发帖的版块，可能暂时不在列表里。
- 不同源的版块ID互不通用，请以 `/sections <源ID>` 的结果为准。
- 一篇文章属于多个版块时，只要有一个被选中就会推送。
- 如果填写的版块ID全部无效，机器人会报错，原有选择保持不变；部分无效时，只保存有效的部分，并告诉你哪些被忽略了。
- 常见英文标签会显示为“中文（英文）”，例如 NodeSeek 的 `daily / tech / info / review / trade / carpool / promotion` 分别显示为日常、技术、情报、评测、交易、拼车、推广。

## 七、推送目标：私聊、群组、频道

所有推送目标都会收到**相同**的推送。每位用户默认最多 10 个目标（以 `/targets` 显示的上限为准）。

### 私聊

发送 `/start`，当前私聊会自动成为推送目标。

### 群组

1. 把机器人拉进群。
2. 由**群管理员**在群里发送 `/addtarget`（不带参数）。

如果你在群里以“匿名管理员”身份发言，机器人无法确认你的身份，请先关闭匿名再试。

### 频道

1. 把机器人添加为**频道管理员**，并开启“发布消息”权限。
2. 获取频道的 chat_id，二选一：
   - 从频道**转发任意一条消息**给机器人（私聊），机器人会回复这个频道的 chat_id；
   - 公开频道可以直接使用 `@频道用户名`。
3. 在私聊中发送：

```text
/addtarget -1001234567890
```

或：

```text
/addtarget @mychannel
```

你本人也必须是该频道的管理员。机器人会检查自己是否有发消息的权限，没有权限时会直接提示。

### 查看与删除

| 命令 | 例子 | 作用 |
| --- | --- | --- |
| `/targets` | `/targets` | 查看推送目标及其目标ID |
| `/deltarget <目标ID>` | `/deltarget 2` | 删除目标 2 |

## 八、状态、历史与暂停

| 命令 | 例子 | 作用 |
| --- | --- | --- |
| `/status` | `/status` | 完整设置：每个源的模式和版块、关键词数量、目标数量等，并列出可能导致收不到推送的问题 |
| `/history [数量]` | `/history 30` | 最近的推送记录，默认 10 条，最多 50 条。每条显示命中的关键词、是否发送成功、发到哪个目标、发送时间 |
| `/pause` | `/pause` | 暂停你的全部推送，设置保留。暂停期间出现的文章不会补发 |
| `/resume` | `/resume` | 恢复推送 |
| `/whoami` | `/whoami` | 显示你的用户 ID；在群里发送还会显示本群的 chat_id |
| `/help` | `/help` | 使用说明。点消息下方的按钮切换分类：订阅与推送方式、关键词与屏蔽词、版块筛选、推送到群/频道、推送规则、状态与历史、管理员命令。也可以直接发送 `/help 版块` 这样的命令 |

### 推送消息长什么样

每条推送是一个可点击的标题，下面是 Telegram 生成的网页预览卡片，点标题或卡片都会打开原帖。卡片的图片、颜色和摘要由 Telegram 和原网页决定，机器人无法修改。

### 发送失败怎么办

- 遇到 Telegram 限流时，机器人会自动等待后重试；网络短暂异常也会重试。
- 如果机器人被移出群组/频道，或者你在私聊里屏蔽了它，`/history` 会显示“❌ 发送失败”和原因。请把机器人重新加回去，或用 `/deltarget` 删除这个目标。
- 群组升级为超级群组后 chat_id 会变化，机器人会自动更新。

## 九、收不到推送时，按顺序检查

1. 发送 `/status`，先按“⚠️ 需要注意”里的提示逐条处理。
2. 用 `/mysources` 确认订阅了正确的源，以及它的推送模式和版块。
3. 关键词推送：用 `/keywords` 确认至少有一条 `✅ 启用` 的关键词，并且文章的**标题或摘要**确实包含它。
4. 设置过版块：用 `/sections <源ID>` 确认文章所在的版块被选中；不确定时用 `/clearsections <源ID>` 恢复全部。
5. 用 `/blocks` 检查是否有屏蔽词误拦截。
6. 用 `/history` 查看是否有“❌ 发送失败”的记录。
7. 刚添加源或刚订阅时，需要等 RSS 出现**新**文章。机器人不会补发旧文章。
8. 管理员可以用 `/feedstatus` 检查源是否读取失败（例如 `HTTP 403`、超时）。

## 十、管理员

设置管理员：先私聊机器人发送 `/whoami` 查看用户 ID，再在服务器上运行 `rss-tg-bot admin 你的用户ID`（会自动重启）。管理员命令也会出现在管理员本人的 `/` 命令菜单里；如果没有出现，先私聊机器人一次，再运行 `rss-tg-bot restart`。

| 命令 | 例子 | 作用 |
| --- | --- | --- |
| `/addfeed <RSS地址>` | `/addfeed https://example.com/feed.xml` | 添加共享源。添加前会先试读一次，确认地址有效 |
| `/delfeed <源ID>` | `/delfeed 3` | 删除源 3，以及所有人对它的订阅、推送模式和版块选择；推送历史保留 |
| `/feedstatus` | `/feedstatus` | 各源的地址、订阅人数、上次检查时间和最近一次错误 |
| `/renumber` | `/renumber` | 整理编号：把**所有用户**的关键词和屏蔽词按现在的顺序重新编为 1、2、3……。会先显示哪些编号会变化，点“确认整理”后才执行。整理后之前记下的编号失效，推送不受影响。服务器上也可以运行 `rss-tg-bot renumber`（会先备份） |

新源第一次抓取只建立“已读基线”，不会推送历史文章。如果第一次读取失败或读到的是空内容，机器人不会建立基线，下次读取成功时再建立，因此不会出现“一下子推送大量旧文章”的情况。

## 十一、权限与白名单

- 默认没有白名单，任何找到机器人的人都能使用。正式使用建议开启白名单：在服务器上运行 `rss-tg-bot allow 用户ID`，每次加一个人。第一次运行时会开启白名单，现有管理员会被自动加入。
- 不在白名单的用户在私聊里会收到提示；在群里机器人不会回应他们，避免刷屏。
- 想加入白名单，先私聊机器人发送 `/whoami`，把显示的用户 ID 发给管理员。
